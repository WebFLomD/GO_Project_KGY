# Учёт личных трат

Веб-приложение на Go для учёта личных расходов.

## Технологии

- **Go** — серверная часть.
- **HTML** — страницы приложения.
- **MySQL** — база данных.
- **XAMPP** — запуск локального сервера MySQL.

## Возможности

- Добавление, просмотр, редактирование и удаление расходов.
- Категории расходов.
- Фильтрация по категории и диапазону дат.

## Как запустить

1. Установите Go и XAMPP.
2. Откройте XAMPP Control Panel и запустите **MySQL**.
3. Создайте базу данных `personal_expenses` и импортируйте `personal_expenses.sql`, если файл содержит SQL-структуру проекта.
4. Проверьте настройки подключения к БД в `config/db.go`.
5. В терминале из папки проекта выполните:

   ```bash
   go mod tidy
   go run .
   ```

6. Откройте в браузере `http://localhost:8080`.

## Структура проекта

- `main.go` — запуск сервера и маршруты.
- `config/` — подключение к БД и SQL-запросы.
- `controllers/` — обработчики страниц и действий.
- `models/` — структуры данных.
- `web/` — HTML-шаблоны.
- `personal_expenses.sql` — SQL-скрипт базы данных.
